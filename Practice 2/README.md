# Filatov Dashboard - интерактивный конструктор дашборда

Практическая работа 2 по фронтенду.

**Выполнил:** Филатов Алексей Кириллович  
**Группа:** М8О-104СВ-26

Одностраничное приложение без фреймворков, сборщиков, npm-пакетов или бэкенда. HTML + CSS + JavaScript (ES-модули).

## Запуск

**Рекомендуемый способ:** открыть папку в VS Code, установить расширение Live Server (только средство запуска, не библиотека приложения), нажать **Go Live** на `index.html`.

**Без установки расширений:** в терминале из папки проекта запустить:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`. ES-модули лучше запускать через локальный HTTP-сервер, а не через `file://`.

Используются системные шрифты. Приложение не зависит от внешних ресурсов и работает офлайн при запуске через локальный сервер.

## Структура

- `index.html` - семантическая разметка и контейнеры UI
- `css/styles.css` - адаптивная сетка, темы и оформление
- `js/app.js` - состояние и обработчики пользовательских сценариев
- `js/widgets.js` - DOM-рендеринг четырёх типов виджетов
- `js/dragdrop.js` - нативный HTML Drag & Drop, Touch Events
- `js/modal.js` - кастомные модальные окна с focus trap
- `js/storage.js` - валидация/версионирование данных, localStorage
- `js/toast.js` - уведомления с автоскрытием

## Возможности

1. Добавление, удаление, сворачивание виджетов; редактирование заголовка двойным щелчком или кнопкой ✎.
2. Заметка: редактирование двойным щелчком, кнопкой или Enter при фокусе; **Ctrl+Enter** для сохранения, **Esc** для отмены, сохранение при потере фокуса.
3. Счётчик: +/- и настройка положительного целочисленного шага.
4. Задачи: добавление, удаление, чекбоксы, прогресс выполнения.
5. График: столбцы на DOM/CSS, ввод до 12 чисел, редактирование данных. При создании имитируется запрос на 500–1000 мс, 15% вероятности ошибки + Retry.
6. Drag & Drop мышью (HTML Drag Events) и пальцем (Touch Events за ручку ⠿). Клавиатура: кнопки ← → в каждой карточке для изменения порядка.
7. Сетка: 3 колонки >1070 px, 2 колонки 651–1070 px, 1 колонка ≤650 px.
8. LocalStorage: данные, порядок, заголовки, содержимое и тема. `version: 1`. Неизвестная/некорректная схема заменяется пустым дашбордом.
9. Собственные модалки: Escape, оверлей, крестик, focus trap, запрет прокрутки страницы.
10. Toast на 3 секунды, пустое состояние, базовая семантика и aria-атрибуты.

## Ручная проверка

- Создать по одному виджету каждого типа, изменить данные и обновить страницу: всё осталось.
- Переместить карточку, обновить: порядок сохранился.
- Свернуть карточку, обновить: состояние сохранилось.
- Переключить тему, обновить: тема сохранилась.
- Создать график: спиннер 0.5–1 сек; при случайной ошибке нажать «Повторить».
- Открыть модалку: проверить Tab/Shift+Tab, Escape, клик по фону и отсутствие скролла.
- Проверить DevTools Responsive на ширине 1440, 768 и 390 px.
- В DevTools Application → Local Storage испортить значение ключа `pulseboard.dashboard`, обновить: без ошибки пустой дашборд.

## Оформление

Простой учебный интерфейс без внешних UI-библиотек: стандартные шрифты, минимальные декоративные элементы, подпись автора и группы.
